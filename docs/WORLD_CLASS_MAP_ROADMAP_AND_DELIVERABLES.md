**Research Summary (Godot/GS/HOI4 best practices, current assets as base):**
- Vector vs raster: Current Polygon2D + high-res stylized bg (europe_grand_theater_ultra_high etc) is ideal. Polys = gameplay (exact for width/attrition/supply/settlement). Bg provides rivers/hills/cities detail without per-pixel ID lookup cost or "muddy" political. Tutorials (YouTube "Godot 4 Ultimate Grand Strategy", "How to make 2D GS Map", Polygon2D docs, Reddit) confirm Polygon2D/Line2D for borders + spatial query or Area2D/CollisionPolygon for pick (we use MapPickGrid spatial — smart for 460+ perf). HOI4 bitmap good for their 13k but requires dedicated pipeline, states grouping, and many artists; players often prefer clean political + simple terrain mapmode over cluttered.
- Mapmodes/layers: Multiple tints or stacked semi-transparent Polygon2D (or shader uniform per mode) for political (clean default), supply (L already), development, settlement vitality, welfare strain, loyalty/foreign mil %, terrain. Dynamic roads/rails as Line2D children from built_road/rail_neighbors (infra overlay exists). Z-order careful (fills 0, routes 58, names 82-100, supply higher). Zoom gates prevent spam.
